# PS5 Network в «Мультимедиа»

Установщик добавляет плитку **PS5 Network** на PS5. Плитка открывает `http://127.0.0.1:8095/` в системном браузере. Для работы нужна запущенная PS5 Network 0.21.

## Установка

1. Распакуйте [архив](../ps5-network-media.zip). Проверьте ELF по `SHA256SUMS.txt`. На Linux выполните `sha256sum -c SHA256SUMS.txt`, на Windows сравните вывод `Get-FileHash .\ps5-network-media.elf -Algorithm SHA256` со значением в файле.
2. Передайте `ps5-network-media.elf` в установленный Payload Manager или запустите через действие **Launch ELF** в PS5 Web File Manager.
3. Дождитесь уведомления **PS5 Network shortcut added to Media**. Откройте **Мультимедиа → PS5 Network** и введите код действующей панели.

Установщик создаёт `/user/app/PSNT08095/sce_sys/param.json` и `icon0.png`. В метаданных стоит категория `65536`, которую используют Payload Manager и PS5 Web File Manager. Для удаления воспользуйтесь меню удаления самой плитки.

При наличии `sceAppInstUtilAppInstallTitleDir` регистрируется конкретный Title ID. Если эта функция недоступна, используется `sceAppInstUtilAppInstallAll`. Общее пересканирование может также зарегистрировать готовые каталоги других приложений в `/user/app/`.

Если системная регистрация вернула ошибку, файлы плитки сохраняются для повторной попытки. Повторный запуск сверяет их с встроенными файлами перед регистрацией.

## Сборка

Используется [PS5 Payload SDK v0.45](https://github.com/ps5-payload-dev/sdk/releases/tag/v0.45) и установленный LLVM. Из этой папки запустите команду с переменной `PS5_PAYLOAD_SDK`, указывающей на SDK.

```bash
sh build.sh
```

Получится `ps5-network-media.elf`. Файлы `param.json` и `icon0.png` включаются в ELF через `assets.S`. Библиотека установки инициализируется модулем `0x80000014`, после чего ELF вызывает функции установки приложений.

На PS5 12.20 проверены запись файлов плитки, успешный ответ регистрации и запись PS5 Network с категорией `65536` в системном каталоге приложений. Открываемая панель имеет тот же код входа, что и при доступе с ПК.
