# Открытие панели на PS5

Импортируйте `ps5-network-open-panel.elf` в Payload Manager. Когда PS5 Network 0.21 уже запущена, откройте ярлык **Payload Manager** на PS5 и выберите этот ELF в списке. Системный браузер откроет `http://127.0.0.1:8095/`. Код входа берётся из уведомления PS5 Network. ПК нужен только для первоначального переноса ELF, если вы используете импорт по LAN.

При остановленной панели приложение покажет уведомление. Сначала запустите свою установленную PS5 Network, затем повторите открытие. По LAN панель по-прежнему доступна по адресу PS5 на порту `8095`.

## Сборка

Из этой папки выполните команду с установленным [PS5 Payload SDK v0.45](https://github.com/ps5-payload-dev/sdk/releases/tag/v0.45).

```bash
"$PS5_PAYLOAD_SDK/bin/prospero-clang" -O2 -Wall -Wextra -Werror \
  open-panel.c -o ps5-network-open-panel.elf
```

ELF проверяет, доступен ли локальный порт, и передаёт адрес штатной панели системному браузеру. Вход, диагностика и настройки находятся в запущенной PS5 Network 0.21.
