# Скриншоты с самой PS5

Готовый инструмент для кадров из системного интерфейса и приложений PS5. Нужный экран открывается на консоли, Python-клиент на компьютере получает изображение по LAN и сохраняет PNG. В комплекте есть ELF, клиент, исходники и контрольные суммы.

В основе — [PS5 DevLoop](https://github.com/griches/PS5_DevLoop) Gary Riches, снимок [118000a](https://github.com/griches/PS5_DevLoop/tree/118000a73dc726f134ee5053b9b04d8bc4605556). Автор проверял его на **13.60**. Для нашей статьи получение снимков и виртуальный контроллер проверены также на **12.20**. Поддержку остальных прошивок нужно проверять отдельно.

## Подготовка компьютера

На Ubuntu или Debian установите Python 3, декодер JPEG XR и конвертер изображений.

```bash
sudo apt update
sudo apt install python3 libjxr-tools imagemagick
```

На macOS с Homebrew используйте следующую команду.

```bash
brew install python jxrlib imagemagick
```

Под Windows эти команды можно выполнять в Ubuntu через WSL. Проверку подключения и запуск клиента выполняйте из того же окружения. Для конвертации клиент поддерживает `magick`, `convert` и, при их отсутствии, FFmpeg. Сторонние Python-пакеты не требуются.

## Запуск на консоли

1. Запустите свою настроенную среду PS5 и Web File Manager. Компьютер и PS5 должны видеть друг друга по LAN.
2. Сверьте SHA-256 файлов в `build/` с `SHA256SUMS.txt`. На Linux из этой папки выполните `sha256sum -c SHA256SUMS.txt`. На macOS подойдёт `shasum -a 256 -c SHA256SUMS.txt`.
3. В Web File Manager загрузите **`build/ps5loop.elf`** в `/data/` и выполните **Launch ELF**. Получится адрес `/data/ps5loop.elf`. Приложение остаётся работать в фоне на порту **9112**.
4. В терминале компьютера перейдите в папку `capture-tools` и задайте реальный адрес консоли вместо примера ниже.

```bash
export PS5_HOST=192.168.1.80
python3 tools/ps5loop.py ping
```

Ответ `ok ps5loop 1 ... pad=closed` подтверждает запуск. Если доступен сетевой ELF-загрузчик на порту 9021, вместо ручного переноса можно выполнить `python3 tools/ps5loop.py load build/ps5loop.elf`. В нашей установке снаружи был доступен файловый менеджер, поэтому ELF запускался через него. Клиент управления использует порт 9112 в обоих вариантах.

## Виртуальный контроллер

Для снимка нужен виртуальный DualSense. В режиме ниже физический контроллер остаётся подключённым.

```bash
python3 tools/ps5loop.py open --beside
python3 tools/ps5loop.py status
```

Обычно активный пользователь определяется автоматически. Если в ответе есть `user=0xffffffff` или `bind=skipped`, получите его ID следующим способом.

1. Загрузите `build/user-id.elf` через Web File Manager и выполните **Launch ELF**.
2. Откройте созданный **`/data/ps5-devloop-user.txt`**. При успешном запросе первая строка содержит `foreground=0x... result=0x00000000`.
3. Закройте прежний виртуальный контроллер и откройте его с полученным значением. В следующем примере `0x12345678` — заглушка, которую нужно заменить.

```bash
python3 tools/ps5loop.py close
python3 tools/ps5loop.py open 0x12345678 --beside
python3 tools/ps5loop.py status
```

Должны появиться действительный пользователь и успешный `bind`. Утилита `user-id.elf` читает состояние UserService и записывает текстовый результат. Аккаунты и настройки пользователя она не меняет.

Если программа на PS5 принимает команды только от первого контроллера, режим `open` без `--beside` может отключить физический DualSense. Для ручной навигации и снимков оставьте `--beside` и открывайте нужные экраны обычным контроллером. Для возврата физического контроллера после отключения нажмите на нём PS.

## Получение кадра

Откройте нужный экран на PS5 и выполните команду на компьютере.

```bash
python3 tools/ps5loop.py shot captures/ps5-network.png
```

Инструмент удерживает Create **1,2 секунды**, ждёт новый файл в галерее, получает его и удаляет именно этот новый снимок через системный API. PNG сохраняется локально, ширина ограничена **1600 пикселями** с сохранением пропорций. Существующие снимки команда `shot` не забирает.

При HDR консоль может выдать **JPEG XR**. Клиент сохраняет рядом исходный `.jxr`, декодирует его в RGB или RGBA и готовит PNG. Исходник JPEG XR остаётся на компьютере.

Нужным меню можно управлять вручную. Для отдельных нажатий с компьютера есть команды ниже.

```bash
python3 tools/ps5loop.py press right
python3 tools/ps5loop.py press cross
python3 tools/ps5loop.py shot captures/next-screen.png
```

После каждого перехода проверяйте фактический экран. В длинной последовательности добавляйте паузы через `wait:500`. Для снимка интерфейса используйте `shot`. Команда `grab` требует отдельного механизма внутри конкретного приложения.

## Завершение

```bash
python3 tools/ps5loop.py close
python3 tools/ps5loop.py raw quit
```

После `ok bye` фоновое приложение завершено. Через файловый менеджер можно убрать загруженный `/data/ps5loop.elf`, вспомогательный ELF и `/data/ps5-devloop-user.txt`, если они больше не нужны. `/data/ps5loop.log` удаляйте только если он появился в вашем сеансе съёмки и нужен был именно для него.

Галерею очищает **`sceContentDeleteByPath`** — вместе с файлом, миниатюрой и записью в базе. Ручное удаление фотографий из `/user/av_contents/` и правка `av_content.db` нарушают согласованность галереи. Если временный кадр остался после обрыва связи, удалите его через штатную галерею PS5.

## Если что-то не получилось

| Результат | Что проверить |
| --- | --- |
| `ping` не отвечает | Адрес консоли, запуск ELF, доступ к порту 9112 и локальная сеть |
| `load` не соединяется с 9021 | Запустите готовый ELF через Web File Manager |
| `user=0xffffffff` | Получите активный ID через `user-id.elf` и повторите `open` с ним |
| `klog=no-device-line` | Проверьте klog и завершите другой клиент чтения журнала на время открытия контроллера |
| `shot no new capture` | Виртуальный контроллер, назначенного пользователя и возможность снимка в текущем экране |
| Вместо кадра открылось меню Create | Закройте его Circle и повторите удержание не короче 1200 ms |
| Сохранился JXR или TIFF | Доступность `JxrDecApp`, ImageMagick или FFmpeg в PATH |

Некоторые системные экраны блокируют захват. В нашем сеансе это встретилось в списке сетевых подключений. Команда вернула ошибку, а предыдущий кадр не выдавала за новый.

Сервис управляет контроллером без авторизации. В этой схеме он работает в домашней сети и завершается после съёмки.

## Исходники и лицензии

- `upstream/` содержит полный неизменённый снимок PS5 DevLoop под **GPL-3.0-or-later**.
- `build/ps5loop.elf` собран из `upstream/payload/main.c` с **PS5 Payload SDK v0.45**.
- `tools/ps5loop.py` сохраняет GPL и дополнен поддержкой RGBA JPEG XR, ImageMagick 6, FFmpeg и вывода 1600 px. Изменения перечислены в `client.patch`.
- `user-id.c` и `build.sh` — собственные вспомогательные исходники под **MIT**. Код используемого SDK сохраняет свою лицензию.
- Соответствующие исходники SDK с его лицензионными уведомлениями приложены в [sdk-source/](sdk-source/ps5-payload-sdk-v0.45-source.tar.gz). Они входят и в автономный архив.

При установленном SDK пересоберите оба ELF командой ниже. Для сборки нужны make, LLVM и Python 3.

```bash
export PS5_PAYLOAD_SDK=/opt/ps5-payload-sdk
bash build.sh
```
