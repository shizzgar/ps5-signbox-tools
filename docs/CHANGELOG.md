# Изменения PS5 Network

## 0.22 — 18 ноября 2026

### Вход с самой PS5

Плитка PS5 Network в «Мультимедиа» открывает локальную панель по `http://127.0.0.1:8095/`. Теперь интерфейс сначала запрашивает `GET /api/local-session` и автоматически получает сеанс, если подключение пришло с самой консоли. Старый токен браузера заменяется новым при повторном запуске панели. Ввод PIN, логина или пароля на PS5 не нужен.

Сервер определяет локальное подключение через `getpeername()` реального TCP-сокета. Заголовки `Host`, `Origin` или `X-Forwarded-For` не могут сами по себе разрешить такой вход. Сохранены проверки адреса назначения, источника запроса и служебного заголовка интерфейса. Для компьютера в LAN действует прежний вход по восьмизначному коду из уведомления PS5. Токен не помещается в URL или журнал.

Существующие плитка и вспомогательный `ps5-network-open-panel.elf` подходят для 0.22: адрес панели остался прежним. Сервис панели должен быть запущен перед открытием плитки.

### Подключение Orbit

В 0.21 проверка запущенного сервиса использовала только `/data/orbit-store/orbit_store.elf`. Обнаружены две сборки сервиса с номером **1.9.0**: кэш размером **31 491 648 байт** и ELF внутри TV-приложения размером **64 974 592 байта**. Их исполняемый код различается. Если приложение запускает встроенную сборку, сравнение с кэшем завершается `ENOENT`, хотя сам файл кэша существует.

В 0.22 проверяется кэш, затем встроенный `app0/orbit/orbit_store.elf` в каталогах `/mnt/sandbox/PPSA99177_<номер>/`. Для каждого кандидата сохраняются прежние проверки ELF, трёх фрагментов кода в памяти, карты памяти и адреса импорта `connect`. Номер версии не используется как доказательство совпадения. При неоднозначном совпадении установка не выполняется. Файлы сервиса и TV-приложения не изменяются.

Диагностика показывает путь, размер и результат проверки каждого кандидата, количество чтений памяти и ошибки чтения. Для обнаруженного случая журнал 0.22 показал:

```text
Orbit reference path=/data/orbit-store/orbit_store.elf bytes=31491648 result=-1 errno=2
Orbit reference path=/mnt/sandbox/PPSA99177_000/app0/orbit/orbit_store.elf bytes=64974592 result=0 errno=0
Orbit image reads=4 failed=0 last_read_errno=0
Orbit connect route installed: ... 1 import slots
Orbit VPN active: ... local API port 34177
```

Если Orbit подключить не удалось, но подключился WebView, интерфейс показывает **«Работает только WebView»** с ошибкой Orbit. API состояния отдельно возвращает `orbit_route` и `webview_route`.

Если сервис Orbit был перезапущен во время перехвата, остановите маршрут и включите его заново: панель выберет новый PID. Автоматическое переподключение после перезапуска сервиса эта версия не добавляет.

### Что проверено

- **PS5 12.20**, сервис Orbit 1.9.0, установленное TV-приложение 1.13.0.
- Вход через loopback API на консоли без PIN и открытие плитки **Мультимедиа → PS5 Network** с геймпада: штатный браузер сразу показывает управление без формы входа.
- Отказ выдавать локальный сеанс клиенту из LAN: HTTP 401 без авторизации.
- Подключение живого Orbit из кэша, затем из встроенного ELF приложения. Во втором случае воспроизведён отказ кэшированного кандидата и успешный выбор встроенного.
- Одновременная установка перехватов Orbit и WebView; штатное снятие перехватов проверено до перезапуска сервиса.
- Три двусторонних TCP-обмена самотеста через sing-box; внешняя проверка HTTPS через HTTP CONNECT и SOCKS5 пройдена на PS5.
- Действующий `config.json` сохранился без изменений.
- 11 проверок C-логики через Python и 5 проверок интерфейса через Node.js. Проверяются граница loopback/LAN, Host/Origin, устаревший и отсутствующий кэш, разные экземпляры монтирования, неверный ELF, неоднозначное совпадение, автоматический вход и отображение частичного подключения.

Новая загрузка игры и повторное прохождение капчи в этом сеансе не выполнялись. Прежний результат около 5 MB/s не является новым замером 0.22.

### Сборка и обновление

Обновляется основной ELF: **`elf/ps5-network-v22.elf`**. Исходный `ps5-network-v21.elf` сохранён для отката; контрольные суммы обоих файлов находятся в `elf/SHA256SUMS.txt`.

Перед заменой нажмите **Остановить**, дождитесь снятия перехватов и нажмите **Завершить работу**. Импортируйте новый ELF в Payload Manager и проверьте, что при следующем запуске выбран он. Профиль находится по прежнему пути `/data/ps5-local-proxy/config.json`, переустанавливать плитку не нужно.

В поставленной сборке 0.22 использован точный встроенный Go-образ исходной 0.21; SHA-256 образа: `13999158916685eec5b78a3764f11aec883d7b0c25d6cb57fbee784c9697604b`. C-оболочка, worker, обработчики и веб-интерфейс пересобраны. Полная сборка ядра из исходников по-прежнему доступна через `./build.sh`; для повторной сборки с уже подготовленным PS5-образом ядра добавлен `PS5_CORE_IMAGE`.
